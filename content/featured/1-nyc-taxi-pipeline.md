Built an end to end data engineering and machine learning pipeline processing 7.9 million plus NYC Yellow Taxi trip records using PySpark on Databricks. Cleaned and validated data at scale, implemented Delta Lake for reliable storage with schema enforcement and time travel recovery, and engineered a Random Forest tip prediction model that improved R2 from 0.33 to 0.52 over baseline linear regression through payment type filtering and non linear feature modeling.

Automated the pipeline using Databricks Jobs and built an interactive Databricks dashboard visualizing trip patterns, fare trends, and model performance.
